# Linna Pub — React redesign

## Start in VS Code

1. Extract the ZIP and open the `linna-pub` folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000 (CRA opens the browser automatically).

## Stack
Create React App, React 18, React Router 6, styled-components, Framer Motion, Lucide React. All application styling is scoped in styled-components inside the component/page files; no global CSS or GlobalStyle.

## Pages
Home, About, Food & Drinks, Activities, Gallery, Contact, and a 404 page.
